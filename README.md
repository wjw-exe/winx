# winx
能让你通过win终端实现部分linux命令行的工具

| 命令 | 用法 |
|------|------|
| `ls` | `ls [-l] [-a] [-s] [路径]` — 列出目录 |
| `ll` | `ll [路径]` — 详细列表 |
| `cd` | `cd <路径\|..\|~\|书签名>` — 切换目录 |
| `pwd` | `pwd` — 显示当前路径 |
| `back` | `back` — 返回上级目录 |
| `tree` | `tree [-L 深度] [路径]` — 目录树 |

### 文件操作
| 命令 | 用法 |
|------|------|
| `mkdir` | `mkdir <目录名> [-p]` — 创建目录 |
| `touch` | `touch <文件名>` — 创建/更新时间戳 |
| `cp` | `cp <源> <目标> [-r]` — 复制 |
| `mv` | `mv <源> <目标>` — 移动/重命名 |
| `rename` | `rename <旧名> <新名>` — 重命名 |
| `rm` | `rm <路径> [-r] [-f]` — 删除 |

### 查看内容
| 命令 | 用法 |
|------|------|
| `cat` | `cat <文件>` — 查看全文 |
| `head` | `head <文件> [-n 行数]` — 查看头部 |
| `tail` | `tail <文件> [-n 行数]` — 查看尾部 |
| `diff` | `diff <文件1> <文件2>` — 文件差异 |

### 编辑与打开
| 命令 | 用法 |
|------|------|
| `edit` / `nano` | `edit <文件>` — 内嵌编辑器（Ctrl+S保存，Ctrl+X退出） |
| `open` | `open <文件\|目录>` — 用系统默认程序打开 |

### 搜索与分析
| 命令 | 用法 |
|------|------|
| `find` | `find <模式> [-t f\|d] [-i] [路径]` — 搜索文件 |
| `info` | `info <文件\|目录>` — 详细信息 |
| `du` | `du [-d 深度] [路径]` — 磁盘使用 |
| `stats` | `stats [路径]` — 文件类型统计 |

### 压缩解压
| 命令 | 用法 |
|------|------|
| `zip` | `zip <输出.zip> <源...>` — 压缩 |
| `unzip` | `unzip <压缩包> [-d 目标]` — 解压 |
| `tar` | `tar -c <归档> <源...>` — 打包<br>`tar -x <归档> [-d 目标]` — 解包 |

### 包管理
| 命令 | 用法 |
|------|------|
| `apt` | `apt install\|remove\|search\|update\|upgrade\|list\|show\|clean <包名>` — 调用系统包管理器 |

### 批量与高级
| 命令 | 用法 |
|------|------|
| `bulk-rename` | `bulk-rename <正则模式> <替换字符串> [路径]` — 批量重命名 |
| `chmod` | `chmod <八进制权限> <文件>` — 修改权限（仅 Unix） |

### 其他
| 命令 | 用法 |
|------|------|
| `bookmark` | `bookmark list\|add <名> [路径]\|del <名>\|go <名>` — 书签管理 |
| `history` | `history` — 查看命令历史 |
| `clear` / `cls` | `clear` — 清屏 |
| `help` | `help` — 显示帮助 |
| `quit` / `exit` | `quit` — 退出 |
